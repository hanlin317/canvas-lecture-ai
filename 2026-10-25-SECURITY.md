# Security Policy

## Supported Version

Security fixes are applied to the latest release of Canvas Lecture AI.

## Reporting a Vulnerability

Do not post credentials, Canvas session files, signed media URLs, API keys, or
other private account data in a public issue. Open a GitHub security advisory
for the repository, or contact the maintainer privately through their GitHub
profile.

Include the affected version, macOS version, reproduction steps, and the
smallest redacted diagnostic sample needed to understand the issue.

## Local Secrets

The application stores AI provider keys in macOS Keychain. Canvas browser
state, application configuration, logs, and SQLite data remain in the user's
Application Support folder. These files must never be committed or attached
to an issue without careful review and redaction.

## Software Updates

Packaged releases accept only an Ed25519-signed update manifest. The DMG is
verified against the signed SHA-256 checksum, and the mounted app is checked for
the expected bundle identifier and version before installation. The previous
app is retained as a rollback copy. The signing private key is stored only as a
GitHub Actions secret and is not included in the repository or app bundle.
