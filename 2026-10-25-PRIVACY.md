# Privacy

Canvas Lecture AI is a local application. It does not operate a hosted
service and does not include analytics or telemetry.

## Data Stored Locally

- Canvas browser session state and a dedicated browser profile
- Discovered course, topic, lecture, and job metadata in SQLite
- Application logs and redacted discovery diagnostics
- Downloaded recordings, slides, transcripts, and generated notes
- Downloaded local Whisper models under the app's Application Support folder
- AI provider keys in macOS Keychain or Windows Credential Manager

Packaged releases store application state in:

```text
~/Library/Application Support/Canvas Lecture AI/
%LOCALAPPDATA%\Canvas Lecture AI\
```

Upgrades from the former Dental Lecture Manager name continue using its existing
Application Support folder when present, preventing loss of saved settings and
sessions. The app also reads legacy Keychain entries for the same reason.

## Network Requests

The application communicates with the Canvas and Echo360 services configured
by the user. AI requests are sent only when the user enables an AI operation,
to the provider selected for that operation. Refreshing a provider's model
list contacts that provider. Local/Ollama requests remain on the configured
local endpoint.

Each pipeline run has a privacy mode. Downloads-only mode prevents AI note
generation. Local-processing mode permits local Whisper and local/Ollama but
rejects cloud AI providers. Cloud-AI mode permits transcript content to be sent
to the provider selected by the user.

When update checking is enabled, the app requests the latest release metadata,
signed update manifest, and optional DMG from this project's GitHub repository.
The app does not send lecture content, Canvas credentials, or AI keys to GitHub.
Sanitized diagnostics contain application version, operating-system details,
feature availability, counts, and job states. They exclude credentials, session
files, signed media URLs, lecture titles, transcripts, notes, local paths, and keys.

## User Responsibility

Use the application only with accounts and educational materials you are
authorized to access. Follow your institution's policies and the copyright
terms applying to lecture material. Do not redistribute downloaded material
without permission.
