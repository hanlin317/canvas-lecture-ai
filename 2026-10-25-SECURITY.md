# Security Policy

## Supported Version

Security fixes are applied to the latest release of Canvas Lecture AI.

## Reporting a Vulnerability

Do not post credentials, Canvas session files, signed media URLs, API keys, or
other private account data in a public issue. Open a GitHub security advisory
for the repository, or contact the maintainer privately through their GitHub
profile.

Include the affected version, operating-system version, reproduction steps, and the
smallest redacted diagnostic sample needed to understand the issue.

## Local Secrets

The application stores AI provider keys in macOS Keychain or Windows Credential
Manager. Canvas browser
state, application configuration, logs, and SQLite data remain in the user's
Application Support folder. These files must never be committed or attached
to an issue without careful review and redaction.

## Software Updates

Packaged releases accept only an Ed25519-signed update manifest. Installers are
verified against the signed SHA-256 checksum; mounted macOS apps are also checked
for the expected bundle identifier and version, and the previous app is retained
as a rollback copy. Apple Developer ID and notarization credentials, Windows PFX
credentials, and the update-manifest signing key are stored only as GitHub Actions
secrets and are not included in the repository or application bundle.
