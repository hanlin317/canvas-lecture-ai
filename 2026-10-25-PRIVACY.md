# Privacy

Dental Lecture Manager is a local application. It does not operate a hosted
service and does not include analytics or telemetry.

## Data Stored Locally

- Canvas browser session state and a dedicated browser profile
- Discovered course, topic, lecture, and job metadata in SQLite
- Application logs and redacted discovery diagnostics
- Downloaded recordings, slides, transcripts, and generated notes
- Downloaded local Whisper models under the app's Application Support folder
- AI provider keys in macOS Keychain

Packaged releases store application state in:

```text
~/Library/Application Support/Dental Lecture Manager/
```

## Network Requests

The application communicates with the Canvas and Echo360 services configured
by the user. AI requests are sent only when the user enables an AI operation,
to the provider selected for that operation. Refreshing a provider's model
list contacts that provider. Local/Ollama requests remain on the configured
local endpoint.

## User Responsibility

Use the application only with accounts and educational materials you are
authorized to access. Follow your institution's policies and the copyright
terms applying to lecture material. Do not redistribute downloaded material
without permission.
